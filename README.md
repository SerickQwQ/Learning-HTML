# My Little Corner

A web beginner's first site. Black and white, four pages, plain HTML / CSS / JavaScript — no framework, no backend, no build step.

- **Live site**: `https://your-domain.com/` (replace after deployment)
- **Stack**: HTML5 · CSS3 · Vanilla JavaScript · Web Manifest

---

## Pages

Switch between four pages using the tabs at the top, or open one directly via hash (e.g. `#projects`).

| Page | Content |
| --- | --- |
| **About** | A short introduction, with an avatar |
| **Quotes** | Six quotes I like |
| **Projects** | Four websites I want to build, plus the order: mind map → framework → code |
| **Useless Machine** | A number-guessing game, 1–1000 |
