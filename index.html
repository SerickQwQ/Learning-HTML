About Me

Hi, I'm a web beginner 👋

I'm a student who is just starting to learn web development. I like quiet places, clean layouts, and designs that don't shout at you.

I write a little code and keep a little diary. This site is my first website. I built it with only HTML, CSS and a bit of JavaScript, and I split it into four pages: about me, my favorite quotes, projects I want to build, and a small useless machine.
